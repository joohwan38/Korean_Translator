## 소개

한국어 다국어 번역기는 엑셀 파일에 있는 한국어 텍스트를 여러 언어로 자동 번역하는 데스크톱 애플리케이션입니다. 로컬에서 AI 번역 모델을 실행하여 번역의 정확성과 개인정보를 보호합니다.

이 도구는 게임, 앱, 웹사이트 등의 다국어 지원을 위한 번역 작업을 간소화하는 데 특히 유용합니다.

## 기능

- **다국어 지원**: 한국어에서 영어, 일본어, 중국어(번체), 태국어, 스페인어로 번역
- **로컬 AI 번역**: Ollama와 최신 LLM을 사용하여 인터넷 연결 없이 로컬에서 번역 실행
- **엑셀 파일 처리**: 표준 형식의 엑셀 파일을 읽고 번역 결과를 저장
- **번역 캐싱**: 이미 번역된 텍스트는 저장하여 재사용하므로 속도 향상
- **다중 처리**: 병렬 번역 처리로 대량의 텍스트 효율적 번역
- **사용자 친화적 인터페이스**: 진행 상황 표시 및 간편한 제어 기능

## 시스템 요구사항

- **운영체제**: 
  - MacOS 10.14 이상 (권장: MacOS 11.0+)
  - Windows 10 이상
- **최소 사양**:
  - RAM: 8GB 이상 (권장: 16GB+)
  - 디스크 공간: 기본 앱 10MB + Ollama 모델 용량(2-8GB)
  - 프로세서: 멀티코어 CPU (권장: 4코어 이상)
- **필수 소프트웨어**:
  - [Ollama](https://ollama.ai/download) (로컬 AI 모델 실행용)
  - Python 3.8 이상 (소스에서 실행하는 경우)

## Ollama 설치 및 설정

이 애플리케이션은 Ollama를 사용하여 로컬에서 AI 모델을 실행합니다. 다음 단계를 따라 설치하세요:

1. [Ollama 공식 사이트](https://ollama.ai/download)에서 운영체제에 맞는 버전을 다운로드합니다.
2. 설치 파일을 실행하고 지시에 따라 설치합니다.
3. 설치 후 Ollama 애플리케이션을 실행합니다.
   - MacOS: 애플리케이션 폴더에서 Ollama 앱을 실행
   - Windows: 시작 메뉴에서 Ollama를 찾아 실행

### 모델 설치하기

번역기에 필요한 언어 모델을 설치해야 합니다. 다음 단계를 따르세요:

1. 터미널(MacOS) 또는 명령 프롬프트(Windows)를 엽니다.
2. 다음 명령어로 권장 모델을 설치합니다:
   ```bash
   ollama pull gemma3:12b
   ```
   - 다른 옵션: `ollama pull llama3.2` 또는 `ollama pull mistral` (더 가볍지만 번역 품질이 더 낮음)

3. 다운로드가 완료될 때까지 기다립니다. 모델 크기에 따라 몇 분에서 수십 분이 소요될 수 있습니다.

> **주의**: 첫 번째 모델 다운로드에는 시간이 걸릴 수 있습니다. 모델 크기는 약 2-8GB이니 충분한 디스크 공간을 확보하세요.

## 사용 방법

### 엑셀 파일 형식

1. 다음 형식으로 Excel 파일을 준비하세요:
   - 시트 이름: "MessageSet" (정확히 일치해야 합니다. 시트이름 불일치를 꼭 확인하세요.)
   - **필수 열: KO, EN, JA, ZH_HANT, TH, ES** (없으면 오류가 납니다.
      (* 깃허브 저장소에서 [translate_templete.xlsx](https://github.com/joohwan38/Korean_Translator/releases/download/download/translate_templete.xlsx) 파일을 받아서 사용하셔도 좋습니다.)
   - "KO" 열에 번역할 한국어 텍스트를 입력하고, 나머지 열은 비워두세요 (번역될 예정)

2. 예시:

| KO | EN | JA | ZH_HANT | TH | ES |
|----|----|----|---------|----|----|
| 환영합니다 |  |  |  |  |  |
| 로그인하세요 |  |  |  |  |  |
| 취소 |  |  |  |  |  |

> **팁**: 애플리케이션 실행 후 "도움말" 버튼을 클릭하면 템플릿 파일을 바탕화면에 생성할 수 있습니다.

### 번역 실행하기

1. 한국어 다국어 번역기 애플리케이션을 실행합니다.
2. "Ollama 확인" 버튼을 클릭하여 Ollama 서버 상태를 확인합니다.
   - 실행 중이 아니면 자동으로 실행하거나 수동 실행 안내가 표시됩니다.
3. 드롭다운 메뉴에서 번역에 사용할 모델을 선택합니다 (권장: llama3.2).
4. "찾아보기" 버튼을 클릭하여 준비한 Excel 파일을 선택합니다.
5. "번역 시작" 버튼을 클릭하여 번역을 시작합니다.
6. 진행 상황이 프로그레스 바로 표시됩니다.
7. 번역이 완료되면 결과가 저장된 Excel 파일의 위치가 표시됩니다.

## 자주 묻는 질문 (FAQ)

### Q: API 가 필요한가요?
A: 현재 버전은 로컬컴퓨터의 GPU를 사용하여 번역합니다. API 가 필요하지 않습니다.

### Q: 얼마나 많은 텍스트를 한 번에 번역할 수 있나요?
A: 기술적인 제한은 없지만, 몇 천 개의 항목을 번역하면 시간이 오래 걸릴 수 있습니다. 대용량 번역의 경우 배치로 나누어 진행하는 것이 좋습니다.

### Q: 번역 품질은 어떤가요?
A: 번역 품질은 선택한 모델에 따라 다릅니다. gemma3:12b 와 같은 최신 모델은 일반적으로 좋은 결과를 제공하지만, 전문 용어나 특수 콘텐츠의 경우 검토가 필요할 수 있습니다.
온라인상의 LLM을 이용하는 것보다 간편하지만 품질은 차이가 있을 수 있습니다.

### Q: 인터넷 연결이 필요한가요?
A: 처음 Ollama 모델을 다운로드할 때만 인터넷 연결이 필요합니다. 모델이 설치된 후에는 인터넷 없이 로컬에서 번역이 가능합니다. 보안문제 없이 사용할 수 있습니다.

### Q: 기존 번역물이 있는 파일의 아래쪽에 신규텍스트를 입력하고 번역하고 싶은데요?
A: 기존 번역물이 있는 자리는 건너뛰고 신규로 비어이있는 번역셀만 번역을 시도합니다. 이전에 사용하시던 파일도 양삭만 맞추면 바로 인식합니다.

## 문제 해결

### Ollama 연결 오류
- **증상**: "Ollama 실행 필요" 또는 "연결 오류" 메시지
- **해결 방법**: 
  1. Ollama 앱이 실행 중인지 확인하세요
  2. 방화벽이 11434 포트를 차단하고 있지 않은지 확인하세요
  3. Ollama를 재시작하세요

### 모델 목록이 표시되지 않음
- **증상**: 드롭다운에 모델이 표시되지 않거나 "모델 없음" 메시지
- **해결 방법**:
  1. "새로고침" 버튼을 클릭하세요
  2. 터미널/명령 프롬프트에서 `ollama list`를 실행하여 설치된 모델을 확인하세요
  3. 모델이 없으면 `ollama pull llama3.2`로 모델을 설치하세요

### 번역이 시작되지 않음
- **증상**: "번역 시작" 버튼을 클릭해도 반응이 없음
- **해결 방법**:
  1. Excel 파일 형식이 올바른지 확인하세요 ("MessageSet" 시트와 필수 열이 모두 맞는지)
  2. Ollama가 실행 중인지 확인하세요
  3. 애플리케이션을 재시작하세요

### 메모리 오류
- **증상**: 대용량 파일 처리 시 "메모리 오류" 메시지
- **해결 방법**:
  1. Excel 파일을 더 작은 파일로 나누세요
  2. 불필요한 애플리케이션을 종료하여 메모리를 확보하세요
  3. RAM 용량이 최소 요구사항을 충족하는지 확인하세요
